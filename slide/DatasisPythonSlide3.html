Aritmetica delle collection

Le collezioni (liste, tuple, set e dizionari)
Possono essere manipolate con semplici operatori
Ogni operazione genera come risultato una nuova istanza della collection

Addizione

Le liste e le tuple usano operatori aritmetici per la concatenazione, non per il calcolo matematico.

  • Addizione (+): Unisce due collezioni creandone una nuova.
lista_a = ["fattura_1.pdf"]
lista_b = ["fattura_2.pdf"]
totale = lista_a + lista_b  # ["fattura_1.pdf", "fattura_2.pdf"]

I Set con tante operazioni

I Set sono i più ricchi di operazioni "aritmetiche". Sono vitali per confrontare dati estratti.

  • Unione (|): Tutti gli elementi di entrambi (senza duplicati).
  • Intersezione (&): Solo gli elementi presenti in entrambi.
  • Differenza (-): Elementi nel primo ma non nel secondo (es. campi mancanti).
  • Differenza Simmetrica (^): Elementi che non sono in comune.
campi_richiesti = {"piva", "data", "totale"}
campi_estratti = {"piva", "totale"}
mancanti = campi_richiesti - campi_estratti  # {"data"}

Operazioni tra dizionari

Da Python 3.9, i dizionari hanno adottato operatori simili ai set per il merging.

  • Unione (|): Crea un nuovo dizionario con le chiavi di entrambi. Se una chiave esiste in entrambi, vince il valore del secondo.
  • Update (|=): Aggiorna il dizionario originale sul posto.
base = {"id": 1, "stato": "aperto"}
nuovi_dati = {"stato": "chiuso", "data": "2024-01-01"}

aggiornato = base | nuovi_dati 
# {'id': 1, 'stato': 'chiuso', 'data': '2024-01-01'}

Orientamento agli oggetti

Python è un linguaggio orientato agli oggetti.
L'operatore + per una lista non significa "somma i numeri dentro", ma "invoca il metodo add della classe lista", che è programmato per unire le sequenze.
Questo è il motivo per cui tra dizionari si usa | e non +: perché l'unione di dizionari è un'operazione logica di set, non una sequenza.

Slicing

Lo slicing permette di estrarre porzioni di liste, stringhe o array con la sintassi:
collezione[start : stop : step]
start: Indice di inizio (incluso).
stop: Indice di fine (escluso).
step: Salto (opzionale, default 1).
Ogni elemento è opzionale 

pagine = ["p1", "p2", "p3", "p4", "p5"]
prime_due = pagine[:2]     # ["p1", "p2"]
ultime_due = pagine[-2:]   # ["p4", "p5"]
pari = pagine[::2]         # ["p1", "p3", "p5"]
inversa = pagine[::-1]     # ["p5", "p4", "p3", "p2", "p1"]

Stessa cosa per le stringhe

Anche le stringhe possono essere trattate come liste di caratteri. 

testo = "Il testo contenuto in questa stringa"
for lettera in testo:
	print(f'Lettera: {lettera}')
prime_5_lettere = testo[:5]        # 'Il te'
ultime_5_lettere = testo[-5:]      # 'ringa'
ultime_5_inverso = testo[-1:-6:-1] # 'agnir'
prime_5_inverso = testo[:5][::-1]  # 'et lI'

Introduzione agli Array Multidimensionali

Le immagini in OpenCV sono array NumPy. A differenza delle liste, un array ha una forma (shape).

  • 2D: Immagine in scala di grigi (Altezza x Larghezza).
  • 3D: Immagine a colori (Altezza x Larghezza x Canali BGR).

Lo slicing multidimensionale usa la virgola per separare le dimensioni:
array[y_slice, x_slice, channel_slice]

Slicing 2D: Ritagliare l'Area di Interesse (ROI)

In Document Automation, ritagliamo spesso un'area (es. il riquadro della P.IVA). 

import cv2
img = cv2.imread("fattura.png") # Supponiamo 1000x1000 pixel

# Ritaglio: Righe (Y) da 100 a 200, Colonne (X) da 300 a 500
roi = img[100:200, 300:500]

Regola d'oro: In OpenCV viene prima la Y (altezza) e poi la X (larghezza).

Slicing 3D: Manipolare i Canali Colore

Un'immagine a colori ha 3 canali: 0:Blu, 1:Verde, 2:Rosso. 

# Estrarre solo il canale Blu (ottimo per carta ingiallita)
canale_blu = img[:, :, 0]

# Azzerare il canale Rosso (Rendi l'immagine più fredda)
img[:, :, 2] = 0

Il simbolo ' : ' da solo significa "prendi tutto per questa dimensione".

Slicing con Step: Thumbnail e Downsampling

Possiamo usare lo step per rimpicciolire un'immagine in modo brutale ma veloce senza funzioni esterne. 

# Prendi un pixel ogni 4: riduce l'immagine al 25% della dimensione
small_img = img[::4, ::4]

Questo è utile per generare anteprime velocissime di documenti pesanti o per saltare righe di pixel durante l'analisi del rumore.

Concetto di view in slicing

Questo è un punto critico per chi lavora con immagini grandi:

In Python standard, lo slicing di una lista crea una copia dei dati.

In NumPy (e quindi OpenCV), lo slicing crea una View.

Cosa significa?
Se scrivi ritaglio = img[0:100, 0:100] e poi modifichi ritaglio, cambierai anche l'immagine originale img!
Per evitare questo, bisogna usare .copy(): ritaglio = img[0:100, 0:100].copy().

Slicing negativo

Lo slicing negativo è comodo per ricavare gli ultimi elementi:
ultime_10_operazioni = logs[-10:].
È molto più efficiente che contare la lunghezza della lista e sottrarre 10.

Perché OpenCV?

Mentre Pillow serve per manipolazioni "editoriali" (crop, resize), OpenCV (Open Source Computer Vision Library) serve per l'analisi e l'elaborazione dei dati visivi.

  • Obiettivo: Massimizzare il contrasto tra testo e sfondo.
  • Nota importante: OpenCV carica le immagini in formato BGR, mentre Pillow in RGB.

Interpolazione

L'interpolazione è il processo matematico usato per stimare i valori di pixel "mancanti" quando trasformiamo un'immagine.
I 4 Algoritmi Principali (Dal più semplice al più complesso)

  • Nearest Neighbor (Vicino più prossimo)
  • Bilinear (Bilineare)
  • Bicubic (Bicubica)
  • Lanczos (Lanczos Resampling)

pip install matplotlib

Algoritmi di Interpolazione in Jupyter

Nearest Neighbor

Logica: È il metodo "pigro". Per ogni nuovo pixel, prende il valore del pixel originale più vicino, senza fare calcoli.

Risultato: Produce un effetto "pixelato" o "a scalini" (aliasing).

Uso: Ottimo per ingrandire pixel-art o icone dove vuoi mantenere i bordi netti, ma pessimo per l'OCR perché distorce le curve delle lettere.

OpenCV: cv2.INTER_NEAREST | Pillow: Image.NEAREST

Bilinear

Logica: Calcola il colore come media pesata dei 4 pixel vicini (2x2). Più il nuovo pixel è vicino a un originale, più quel colore "pesa" nel calcolo.

Risultato: L'immagine è più fluida, ma tende a diventare un po' sfocata (blur).

Uso: È il compromesso standard. Molto veloce, ideale per applicazioni real-time o video.

OpenCV: cv2.INTER_LINEAR (default) | Pillow: Image.BILINEAR

Bicubic

Logica: Considera un'area di 16 pixel vicini (4x4) e usa un polinomio di terzo grado (una curva cubica) per stimare il valore.

Risultato: Molto più nitida della bilineare. Mantiene meglio i dettagli sottili e i contrasti.

Uso: Lo standard professionale per l'upscaling di fotografie e documenti. Consigliato per l'OCR.

OpenCV: cv2.INTER_CUBIC | Pillow: Image.BICUBIC

Lanczos

Logica: Usa una funzione matematica complessa chiamata Sinc windowed su un'area ancora più vasta (solitamente 8x8, cioè 64 pixel).

Risultato: È l'algoritmo di più alta qualità. Produce i bordi più netti e riduce al minimo gli "artefatti" (ombre strane intorno alle lettere).

Uso: Il "Gold Standard" per il document processing di alta qualità. È più lento degli altri, ma con i computer moderni la differenza è trascurabile per singoli documenti.

OpenCV: cv2.INTER_LANCZOS4 | Pillow: Image.LANCZOS

Thresholding: Il potere del Bianco e Nero

L'OCR lavora meglio su immagini "binarie" (solo pixel 0 o 255).

  • Simple Threshold: Usiamo un valore fisso (es. 127). Poco efficace con luce non uniforme.
  • Otsu's Threshold: Calcola automaticamente la soglia ideale basata sull'istogramma dell'immagine.
  • Adaptive Threshold: Calcola la soglia per piccole regioni. Fondamentale per scansioni con ombre o carta ingiallita.

Thresholding

# Otsu's Thresholding
_, o_thresh = cv2.threshold(gray, 0, 255,
           cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# Adaptive Thresholding
#    (Ideale per documenti vecchi/ombreggiati)
a_thresh = cv2.adaptiveThreshold(gray, 255,
                 cv2.ADAPTIVE_THRESH_GAUSSIAN_C, 
                 cv2.THRESH_BINARY, 11, 2)

Rimozione del Rumore (Denoising)

I vecchi documenti presentano spesso "grana" o macchie dovute all'invecchiamento.

  • Median Blur: Eccellente per rimuovere il rumore "sale e pepe" (puntini neri/bianchi sparsi).
  • Gaussian Blur: Utile per ammorbidire i bordi prima di un'estrazione di contorni.
# Rimuove i puntini mantenendo i bordi
#     del testo abbastanza nitidi
denoised = cv2.medianBlur(gray, 3)

Non-Local Means 1/2

A differenza del Median Blur (che spesso impasta i caratteri), l'algoritmo NLMeans cerca motivi simili in tutta l'immagine per filtrare il rumore, preservando la nitidezza dei bordi delle lettere.

# Algoritmo NLMeans
# Parametri da testare: h, templateWindowSize, searchWindowSize
denoised = cv2.fastNlMeansDenoising(img, None, h=30.0, templateWindowSize=7, searchWindowSize=21)

Non-Local Means 2/2

I parametri

  • h (Luminance Layer): È la forza del filtro.
    • Valori bassi (5-10): Rimuove poco rumore ma mantiene i dettagli finissimi.
    • Valori alti (30-50): Rimuove macchie pesanti ma può "sbiadire" il testo sottile.
  • templateWindowSize: Dimensione del blocco usato per il confronto (solitamente 7). Deve essere dispari.
  • searchWindowSize: Dimensione che viene utilizzata per calcolare la media ponderata per determinati pixel.

Rimozione del Background "Texture"

Molti documenti hanno una carta ingiallita o una grana che disturba. Possiamo usare la morfologia per stimare lo sfondo e "sottrarlo" all'immagine originale.

kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (15,15))
background = cv2.morphologyEx(img, cv2.MORPH_DILATE, kernel)

out_gray = cv2.divide(img, background, scale=255)

Parametri da modificare:

kernel size (15,15): Deve essere più grande dello spessore dei tratti del testo. Con un valore troppo piccolo (es. 3,3), sparirà anche il testo.

Contrasto Adattivo: CLAHE

Spesso i documenti vecchi hanno un testo sbiadito. Lo "Stretch" del contrasto normale amplifica anche il rumore. CLAHE (Contrast Limited Adaptive Histogram Equalization) opera su piccole regioni dell'immagine in modo indipendente. 

# Creazione dell'oggetto CLAHE
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))
cl1 = clahe.apply(img)

show(cl1, "Contrasto Adattivo CLAHE")

Provare a modificare:

  • clipLimit: Controlla quanto contrasto aggiungere.
    • Valore 1.0: Nessun cambiamento.
    • Valore 5.0: Contrasto estremo (ottimo per inchiostri molto sbiaditi, ma occhio al rumore).
  • tileGridSize: Divide l'immagine in una griglia. (8,8) è lo standard, ma su documenti con scritte molto piccole potrebbero voler provare (16,16).

Trasformazioni Morfologiche

Queste tecniche "gonfiano" o "assottigliano" i pixel bianchi (o neri).

  • Erosione: Utile per separare caratteri che si toccano.
  • Dilatazione: Utile per unire tratti di penna interrotti (handwriting) o rendere più leggibile un testo sbiadito.

Dilatazione ed Erosione

kernel = np.ones((2,2), np.uint8) # definisce la dimensione dell'area

# Rende il testo più spesso (utile per testi molto chiari)
dilation = cv2.dilate(gray, kernel, iterations=1)

# Rende il testo più sottile
erosion = cv2.erode(gray, kernel, iterations=1)

Correzione dell'inclinazione (Deskewing)

Un documento inclinato anche di pochi gradi rovina la lettura dell'OCR (specialmente per le tabelle).
Dobbiamo trovare l'angolo del testo e ruotare l'immagine. 

def get_skew_angle(cv_img):
    # Invertiamo i colori (testo bianco su sfondo nero)
    new_img = cv2.bitwise_not(cv_img)
    coords = np.column_stack(np.where(new_img > 0))
    angle = cv2.minAreaRect(coords)[-1]
    if angle < -45:
        angle = -(90 + angle)
    else:
        angle = -angle
    return angle
# La rotazione effettiva si fa con
#     cv2.getRotationMatrix2D e cv2.warpAffine

Eliminazione di un colore

Analizzando una parte del documento che non contiene testo, si possono isolare i colori dello sfondo.
In base alla presenza di quei colori nell'intera immagine, si crea una maschera da applicare all'immagine portando al colore bianco i pixel individuati.

Nell'esempio specifico l'immagine viene convertita al modello di colori HSV.
Viene realizzato un grafico di presenza dei colori per individuare i range di colori da togliere.
Dal grafico si ricava il range delle componenti H e S e si crea la maschera.
A tutti i pixel dell'immagine in RGB con un valore nella maschera viene assegnato il colore bianco.

Perché questa combinazione è la scelta migliore?

cv2.divide (Correzione dell'illuminazione): Invece di fare una semplice sottrazione, la divisione corregge la variazione di luminosità. Elimina istantaneamente la tonalità giallastra e la sfumatura scura ai bordi dell'immagine, lasciando uno sfondo perfettamente bianco uniforme.

cv2.THRESH_OTSU: Il testo ha caratteri molto scuri e ben definiti rispetto allo sfondo. L'algoritmo di Otsu trova la soglia di binarizzazione perfetta in modo dinamico, separando nettamente l'inchiostro dalla carta virtuale.

Rimozione del pattern a righe: Il pattern di scansione verticale presente nell'immagine originale svanisce quasi completamente dopo la divisione con il background morfologico, evitando che l'OCR confonda le linee verticali con lettere come "l", "i" o "1".
